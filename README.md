# Acxiom CRM

This is a customer relationship management app made with ASP.NET Core MVC. It can be used to manage customers, leads, opportunities, follow-ups, and activities.

## Run the project

You need the .NET 10 SDK installed.

```bash
git clone https://github.com/Satwik99nuts/CRM--Customer-Relationship-Management.git
cd CRM--Customer-Relationship-Management
dotnet run
```

On Windows, you can also double-click `start-crm.bat` to start the app. Keep the window open while using it, and press **Ctrl+C** to stop it.

The app uses a SQLite database named `acxiomcrm.db`. It applies database migrations when it starts.
